# Port Security Notes (CCNA)

## What this is
A cleaned-up, structured version of raw notes on **Cisco Port Security**, originally
taken while watching a NetAcad-style video. The rambling voice-to-text style notes
have been reorganized into clear sections, tables, and highlighted definitions so
they're easier to study and review.

## Files
- `Port_Security_Notes.docx` — the formatted notes, ready to read or print.

## Contents / Sections
1. **Introduction to Port Security** — what it is, per-interface configuration, default err-disable behavior, worked example.
2. **Why Use Port Security** — MAC spoofing, MAC table exhaustion, and how limiting MAC addresses helps.
3. **Port Modes** — access vs. trunk vs. dynamic, and administrative mode commands.
4. **Port Status** — Secure-up, Secure-shutdown, Secure-down, Disabled.
5. **Violation Modes** — Protect, Restrict, Shutdown (with strictness comparison).
6. **Aging Time** — Absolute vs. Inactivity aging, with examples.
7. **Address Limits & Sticky MAC Addresses** — max address counts and how sticky MAC survives a reload.

## Source
Based on the uploaded file `Port_security.docx` (raw personal notes).

## Suggested use
Good for quick review before a CCNA quiz/exam — the tables (violation modes, aging
types, port status) are designed to be memorized quickly.
